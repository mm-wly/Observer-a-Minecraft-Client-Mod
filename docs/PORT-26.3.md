# Minecraft 26.3 移植说明

版本：Observer 2.1.0；日期：2026-10-24。

## 兼容性与构建

Minecraft 26.3 存在 SDL、渲染和注册表相关改动；Fabric 移除了部分旧 API。Observer 未使用这些被移除的接口，现有生产代码在新依赖下可编译，无需重写扫描架构。依赖为 Java 25、Loader 0.19.5、Fabric API 0.161.0+26.3；源码采用 Loom 1.17.12、Gradle Wrapper 9.6.0。

本次标准 Gradle 依赖下载未完成。交付 JAR 使用本机安装的原版与 Fabric 依赖、JDK 25 编译打包；不是旧 JAR 仅修改版本声明。源码包含标准 Gradle 构建配置，但没有声称在线构建已验证。

## 新结构和注册表

新增 18 个 abandoned_camp_<biome> 规则及统一 abandoned_camp 查询。RuleCatalog 指定精确群系、至少 12 个白色羊毛楼梯、3 个栅栏、1 个箱子或木桶、4 个泥土小径。Rule 支持以等号标记精确群系条件，避免 forest 与其他包含 forest 的群系混淆。CandidateMerger 使用营地合并策略，减少帐篷跨分节的碎片结果。

核对 26.3 原版 180 个帐篷模板：楼梯至少 20 个、栅栏至少 3 个、储物容器至少 1 个、小径至少 6 个；5 个模板不含草床，因此草床仅用于边框材料，不设为必需。材料阈值留有余量，仍然可能误报玩家建筑，也不能保证损坏结构的检出。新方块、实体与群系沿用注册表动态查询，无需添加固定白名单。坐垫是实体。

原版结构模板 NBT 调色板字段改为 id / properties；模板审计读取已调整，生产扫描直接读取 BlockState，不依赖模板 NBT。

## 距离外观

令 d 为视点到边框表面的最近距离，f = 1 / (1 + d² / 32²)。
透明度 alpha = 100 + 150f，线宽 width = 1.5 + 1.5f px。
近处保持 alpha 250、3 px；远处趋近 alpha 100、1.5 px。此前最低值为 40 和 0.75 px。RGB 不变，仍然随距离平滑衰减。实际显示受分辨率与渲染环境影响，本次未进行世界内视觉验收。

## 已完成的有限验证

- 生产源码针对实际 26.3 游戏与 Fabric 依赖编译成功。
- 164 项自动化检查全部通过；包括原版结构 ID / 材料存在性、180 个帐篷模板四向旋转、跨分节偏移、错误群系/维度和仅羊毛的负例。
- 独立客户端加载 Observer 2.1.0，完成窗口、资源、声音及纹理图集初始化，未见启动 Mixin 错误。离线测试账号产生的联网认证失败不作为 Mod 错误。
- 未执行完整世界内回归、视觉验收或新版性能基准。交付源码不附带测试。
